# EcoEnergía — Pequeños hábitos, grandes cambios
Proyecto académico enfocado en promover el ahorro energético y el consumo responsable de electricidad.
Vinculación con el Objetivo de Desarrollo Sostenible 7 (ODS 7): Energía asequible y no contaminante.
EcoEnergía propone herramientas digitales, recomendaciones prácticas y recursos educativos para fomentar hábitos sostenibles.
El orientador de consejos funciona como una demostración interactiva. El formulario y la página de confirmación son simulados: no se almacenan datos personales, no se envían correos ni se programan recordatorios reales.
